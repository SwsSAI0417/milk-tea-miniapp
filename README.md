# 奶茶小屋 🧋

基于微信云开发的奶茶点单微信小程序

## 功能模块

- **首页**：轮播图、分类导航（8个品类）、商品列表、快捷加购
- **分类页**：按类别筛选商品展示
- **详情页**：商品信息、规格选择（杯型/糖度/温度）、加入购物车/立即购买
- **购物车**：商品列表、数量增减、全选/单选、勾选结算
- **订单页**：订单列表、状态查看（待支付/待配送/已完成）、删除订单
- **个人中心**：用户头像昵称、订单统计快捷入口、退出登录
- **登录/注册**：账号密码验证、用户名查重

## 技术栈

- 前端：微信小程序原生框架（WXML / WXSS / JavaScript）
- 后端：微信云开发（云函数 × 4）
- 数据库：云数据库 MongoDB（5张数据表）

## 云函数

| 云函数 | 功能 |
|--------|------|
| productCloud | 获取轮播图、商品列表、商品详情、按分类查询 |
| userCloud | 用户注册（含查重）、登录验证、获取用户信息 |
| cartCloud | 查询购物车、加入商品（同规格自动累加）、修改数量、删除商品、清空购物车 |
| orderCloud | 创建订单、查询订单列表、更新订单状态、删除订单 |

## 数据表

| 集合 | 说明 |
|------|------|
| products | 商品信息（名称/价格/图片/分类/规格/描述） |
| banners | 轮播图（图片/排序） |
| users | 用户信息（用户名/密码/手机号） |
| cart | 购物车记录（关联用户ID和商品ID） |
| orders | 订单记录（订单号/商品/总价/状态） |

## 项目结构

```
miniprogram/
├── pages/
│   ├── index/         # 首页
│   ├── category/      # 分类页
│   ├── detail/        # 商品详情
│   ├── cart/          # 购物车
│   ├── orders/        # 订单页
│   ├── profile/       # 个人中心
│   ├── login/         # 登录页
│   └── register/      # 注册页
├── images/            # 图片资源
│   ├── banners/       # 轮播图
│   └── goods/         # 商品图片
└── app.js             # 全局逻辑 & 云函数调用封装

cloudfunctions/
├── productCloud/      # 商品云函数
├── userCloud/         # 用户云函数
├── cartCloud/         # 购物车云函数
└── orderCloud/        # 订单云函数
```

## 使用说明

1. 微信开发者工具导入项目
2. `app.js` 中修改 `env` 为你的云开发环境 ID
3. 右键每个云函数文件夹 → 上传并部署：云端安装依赖
4. 云数据库中创建集合并导入商品数据
5. 编译运行
